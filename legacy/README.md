# Retired files

Everything here was removed from `public/` on 15 October 2026 (FIXES.md, F04) so GitHub Pages
no longer publishes it. Nothing in the four live pages references these files.

- `public/flavours.html`, `outlets.html`, `contact.html` and their bundles (`gelato*.js/css`, `menu.js`,
  `krushna.js/css`): the retired Mr Gelato site.
- `public/concept/` and `public/experience-sample/`: design concepts.
- `public/assets/...`: unused images, plus the original PNG masters (`exterior.png`, `interior.png`,
  `brownie.png`, `logo.png`, the two atlases) that the live pages now serve as WebP.
- `public/menu-discovery.js` and `menu-discovery.css` (moved in Round 4, FIXES.md M-series): the old menu
  search and size filters, replaced by `menu-page.js`.

The sources for the retired bundles are still in `src/` and `components/`; `build.cjs` no longer builds them.
